# Entregas semanales

Una entrega por semana, nombrada por semana ISO: `AAAA-Www.md` (p. ej. `2026-W41.md`).

Cada entrega contiene:

1. Resumen ejecutivo (qué se graba esta semana y por qué).
2. Guiones completos de los vídeos seleccionados.
3. Ideas de reserva.
4. Descartes destacados con su motivo (para no volver a proponerlos).
5. Tendencias clave de la semana.

Si el usuario comparte resultados reales de un vídeo publicado, añadirlos a la entrega correspondiente y a `formatos/series.md`.
