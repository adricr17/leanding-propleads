# Registro de series de PHARAON

Memoria viva de los formatos propios del estudio. El Director Creativo lo consulta antes de cada semana y lo actualiza después de cada entrega.

Regla: si un formato funciona, no se abandona por buscar novedades.

## Cómo registrar una serie

```
### [Nombre de la serie]
- Estado: [semilla / en prueba / activa / en pausa / cerrada]
- Premisa: [una frase]
- Elementos fijos: [intro, frase, música, grafismo, personaje, reglas del juego]
- Protagonistas: [artistas / clientes / personajes]
- Episodios publicados: [fecha · título · resultado si se conoce]
- Próximos episodios posibles: [...]
- Aprendizajes: [qué ha funcionado y qué no, con datos reales si el usuario los aporta]
```
